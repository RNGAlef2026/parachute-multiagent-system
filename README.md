# Parachute Multi-Agent System

Proyecto académico para comparar diferentes arquitecturas de
orquestación de sistemas multiagente.

## Arquitecturas

El mismo problema será implementado utilizando tres arquitecturas:

- Centralizada
- Jerárquica
- Descentralizada

## Funcionalidades

El sistema integrará:

- Base de conocimientos de FAQs.
- Consulta meteorológica mediante Open-Meteo.
- Evaluación de condiciones para realizar saltos.
- Calendarización de citas.
- Agentes especializados utilizando OpenAI Agents SDK.

## Estructura

- `centralized/`: arquitectura centralizada.
- `hierarchical/`: arquitectura jerárquica.
- `decentralized/`: arquitectura descentralizada.
- `shared/`: integraciones y lógica compartida.
- `diagrams/`: diagramas de las arquitecturas.
- `report/`: documentación final.
